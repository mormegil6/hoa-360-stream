Ambisonic Box

A spatial-audio 360° video stream: third-order Ambisonic sound (16 channels) rotated to follow your view and binauralized in real time, delivered live over MPEG-DASH.

To view this stream please enable JavaScript, and consider upgrading to a web browser that supports HTML5 video.

The stream is idle. It stops automatically when nobody is watching, so the server is not encoding around the clock.

About

A Docker toolchain for end-to-end immersive broadcasting: live 360° video with Higher-Order Ambisonic audio, built on Envelop Earshot, Shaka Packager and the HOAST360 player.
